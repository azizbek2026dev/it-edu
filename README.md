# IT Control — Senior IT Coordinator Dashboard

O‘zbek tilidagi, responsive IT koordinatori boshqaruv paneli.

## Ishga tushirish
1. `index.html`, `styles.css` va `app.js` fayllarini bir papkada saqlang.
2. `index.html` faylini brauzerda oching. Server yoki paket o‘rnatish shart emas.

## Tayyor funksiyalar
- Responsive dashboard va mobil menyu
- IT murojaatlari jadvali va qidiruv
- Yangi murojaat yaratish oynasi
- Vazifalarni bajarildi deb belgilash va progress
- CSV formatida murojaatlar hisobotini eksport qilish
- Bildirishnoma/toast xabarlari
- Qurilmalar inventari, SLA va faoliyat ko‘rsatkichlari uchun dashboard UI

## Muhim
Bu frontend demo: ma’lumotlar brauzer ichidagi namunaviy ma’lumotlar bilan ishlaydi. Login, server, ma’lumotlar bazasi, rollar va real bildirishnomalar uchun backend/API ulash kerak.
